# Bundled Artwork

## Desktop Wallpaper

Asset: `app/src/main/res/drawable-nodpi/desktop_wallpaper.webp`.

Original artwork generated for MagicDesk with the built-in Codex image generation
tool. The delivered image is 1672 x 941 pixels, encoded as WebP at quality 90,
method 6. It contains no text or logo and supports centered landscape,
ultrawide, and portrait crops. The app decodes it without resource-density
scaling, then prepares a display-sized pixel frame.

## Replacement Criteria

Keep the central crop usable on portrait and ultrawide displays, without important
objects at the edges. Use low visual clutter and enough contrast for desktop icon
labels. Bundle original raster artwork without text, logos, watermarks or UI.
Record provenance, delivered dimensions and encoding when replacing the asset.
