MagicDesk 1.4 adds external-display recording and an integrated command
console.

- Records the external desktop with internal audio and configurable resolution
  and bitrate.
- Adds **Diagnostics > Console** for one-off Shizuku shell commands with an
  explicit privilege display, confirmation, exit status, and copyable output.
- Improves explicit windowed launches and task and pointer restoration when
  switching or reopening desktop applications.

Requires Android 16 / API 36 or newer and an authorized Shizuku service.
