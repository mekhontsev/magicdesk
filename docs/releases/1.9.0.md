# MagicDesk 1.9.0

MagicDesk 1.9 turns the native Android desktop into a more complete workstation
and gives its window, terminal, and automation layers a shared, testable
architecture. Applications still run as ordinary Android tasks: the release
does not stream them, embed them in replacement views, or introduce a guest
operating system.

## Native Windowing And Sessions

- Rebuilds fullscreen task switching around stable task ownership. On external
  and simulated desktops, each fullscreen task keeps its own ordering plane;
  the phone desktop retains its existing session hierarchy. Switching no longer
  needs to reparent, resize, or briefly convert a fullscreen application to a
  freeform window.
- Unifies taskbar activation, `Alt+Tab`, Open tasks, and MCP focus through the
  same Activate/Demote policy. This keeps application-requested fullscreen and
  fullscreen video intact while mixed fullscreen and freeform workspaces are
  reordered.
- Makes Show Desktop conceal the complete visible workspace, including
  independently organized fullscreen tasks, and restores the saved live task
  order when requested.
- Improves native caption recovery, task focus, Back behavior, taskbar
  visibility, startup placement, display removal, and cleanup after an
  interrupted desktop session.
- Persists live task mode, bounds, visibility, and stacking when a desktop is
  closed or a display disconnects. Tasks that Android or the user closed are
  not relaunched.

## Console, Termux, And Desktop Commands

- Replaces the built-in Console command runner with a lifecycle-owned
  interactive PTY terminal supporting ANSI and 256-color output, alternate
  screens, terminal mouse input, selection, clipboard, and live resize.
- Adds multiple independent Termux-backed Console windows. Each is a native
  Android task with its own PTY, shell, current directory, process lifecycle,
  saved geometry, and task-switcher entry. Foreground programs such as `mc` and
  `nvim` are shown by name.
- Integrates Console and Termux execution with Files, drag and drop, Start,
  `.desktop` files, and terminal application shortcuts. The ordinary Termux
  activity remains available.
- Deepens Termux:X11 integration with startup-state inspection, viewer launch
  and reconnect handling, while keeping X11 independent from the native
  multi-window Console workflow.

## Semantic Automation

- Adds an optional authenticated MCP server on the local loopback interface.
  It exposes typed desktop, task, window, UI, Files, capture, diagnostics, and
  interactive-terminal operations together with bounded state, events, traces,
  screenshots, pixel samples, and application crash/ANR observations.
- Adds a smaller Android App Functions surface for authorized system agents on
  supported Android versions.
- Routes automation through the same production controllers used by the UI and
  keyboard shortcuts. MCP does not implement a second window manager, and its
  developer and shell-capable tools remain behind separate settings.
- Allows MCP to start before Shizuku is ready after MagicDesk has been opened,
  then promotes the same runtime when the authorized shell service appears.

## Desktop Workflow And Diagnostics

- Adds application context actions to Start and the taskbar, including Android
  application settings, explicit launch modes, and direct Console/Termux
  workflows where available. Auto launch remembers the last explicit Windowed
  or Fullscreen choice.
- Improves Start, taskbar, popup, right-click, built-in Files and Console window,
  and console-toolbar behavior for repeated mouse and keyboard use.
- Expands diagnostics and self-tests with application health, pointer recovery,
  task ownership, native caption and snap input, fullscreen lifecycle, Back
  navigation, display-removal cleanup, and structured runtime events.

## Requirements And Boundaries

- Android 15 / API 35 or newer
- The official Shizuku application with an authorized running service
- Firmware that provides usable native Android freeform windows

Root is not required by MagicDesk. The separate Display Fixes development APK
is available only for firmware that hides native external-display timings from
shell UID 2000; it is not part of this tagged release.

Native captions, external video output, Miracast, application task hosting, and
physical-input routing remain firmware capabilities. Some applications also do
not tolerate forced freeform mode; use their remembered Auto or Fullscreen mode
when necessary. Termux-backed Console windows require Termux and its documented
`RUN_COMMAND` permission.

Before updating from 1.8, use **Close desktop** so the current live workspace is
saved cleanly, then install 1.9 over the existing application. Desktop files,
settings, pins, shortcuts, widgets, and saved window state are retained.
