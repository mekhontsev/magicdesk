# MagicDesk 1.9.0

MagicDesk 1.9 makes Android desktop sessions more consistent and adds a real
terminal and automation layer. Applications remain ordinary Android tasks; no
streaming, guest system, or replacement application views are involved.

## Highlights

- Fullscreen tasks keep their mode and application state while switching from
  the taskbar, Open tasks, `Alt+Tab`, or MCP. Mixed fullscreen and freeform
  workspaces, Show Desktop, Back, native captions, and display cleanup are more
  predictable.
- The built-in Console is now an interactive PTY terminal with ANSI and
  256-color output, alternate screens, mouse input, selection, clipboard, and
  live resize.
- Termux can provide multiple independent Console windows. Each window has its
  own shell, working directory, process state, geometry, and taskbar entry.
- Files, Start, drag and drop, `.desktop` files, and terminal shortcuts share
  the same shell and Termux execution backends. The regular Termux application
  remains available.
- Optional local MCP automation exposes typed desktop, task, Files, terminal,
  capture, and diagnostics operations. It uses the same production controllers
  as the UI and keyboard shortcuts.
- Diagnostics and the desktop self-test now cover more window, focus, input,
  launcher, display-removal, and application-health behavior.

## Requirements

- Android 15 / API 35 or newer
- The official Shizuku application with an authorized running service
- Firmware with usable native Android freeform windows

Root is not required. Termux-backed Console windows require Termux and its
documented `RUN_COMMAND` permission. Native captions, video output, Miracast,
and physical-input routing remain firmware capabilities.

Before updating, use **Close desktop**, then install 1.9 over the existing
application. Settings, desktop files, pins, shortcuts, widgets, and saved
window state are retained.
