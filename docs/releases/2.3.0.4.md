# MagicDesk 2.3.0.4

- Choose the Linux account and whether to start system services when opening a Linux desktop, application or terminal. Supports systemd, OpenRC and runit. For existing installations, refresh the guest helper with the matching installer and `--resume`.
- Uses standard Android window placement on Honor firmware that exposes window scaling but does not let apps change it.
- Includes [Shroot 1.0.5](https://github.com/mekhontsev/shroot/releases/tag/v1.0.5), with fixes for process cleanup, debugger notifications and filesystem operations in nested Linux sessions.
