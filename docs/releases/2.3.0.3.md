# MagicDesk 2.3.0.3

Includes Shroot 1.0.4. Fixes since MagicDesk 2.3:

- Guest debuggers and nested Linux sessions handle differences between ARM64 kernels when a debugger changes a system call. The guest's syscall filter checks the arguments that will actually run.
- Fixes an illegal-instruction crash during Linux login or package updates on some ARM64 devices.
- Linux sessions can recover if Android kills an idle memory helper, including while APT is running.
- Fixes a Linux 5.15 hang after a guest process crashes during a core dump. The parent can collect the child's exit status.
