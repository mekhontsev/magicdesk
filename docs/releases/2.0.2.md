# MagicDesk 2.0.2

- Added a Debian 13 Plasma 6 profile to the Linux installer, with X11 and Wayland
  desktop launchers for Shroot. No Termux or Android root is required.
- Added optional hardware-accelerated Plasma Wayland on compatible Adreno GPUs.
  The installer builds private, patched KWin and Mesa libraries; software rendering
  remains available.
- Fixed Turnip GPU timestamp handling and added DMA-BUF fence synchronization for
  the nested KWin compositor.
- Improved X11 compatibility with clients requesting live DRI3 pixmap export.

To try Plasma, run in a MagicDesk Shell console:

```sh
magicdesk download https://raw.githubusercontent.com/mekhontsev/magicdesk/main/scripts/install_linux.sh ~/install_linux.sh
sh ~/install_linux.sh --distro debian --name plasma --gui plasma --gpu turnip
```

The accelerated Wayland desktop was tested with Debian 13, KWin 6.3.6 and
Adreno 840. Installation builds native libraries and needs several GB of space.
See the [Linux installer guide](https://github.com/mekhontsev/magicdesk/blob/v2.0.2/docs/guest-runtime.md#linux-installer)
for software rendering, resuming an existing environment and desktop limitations.
