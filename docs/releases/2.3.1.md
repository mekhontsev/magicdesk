# MagicDesk 2.3.1

- Choose **Cover** to fill the display or **Contain** to show the whole wallpaper, including video, in Settings > Appearance or the desktop context menu.
- Apps that hide the system bars open in a window on Desktop displays. Games and non-resizable apps still default to fullscreen; explicit and remembered choices take precedence.
- Wayland windows support direct multitouch. A finger still clicks in applications that only understand a mouse.
- Android keyboards can now correct an existing word in Wayland apps without duplicating it or inserting the correction at the wrong cursor position.
- Includes [Shroot 1.0.6](https://github.com/mekhontsev/shroot/releases/tag/v1.0.6), which fixes interrupted waits affecting OpenCode and avoids premature startup timeouts in nested Linux sessions.
