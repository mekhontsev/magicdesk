# MagicDesk 2.3.1

- Added selectable wallpaper alignment (`resources.wallpaperFit`): **cover** fills the display and crops overflow (the existing default), **contain** shows the whole source centered over the theme backdrop. It applies to images, animated images, video and the shared custom wallpaper; AGSL shaders still fill the output. Set it in Settings > Appearance or the desktop context menu.
- Immersive applications (text editors, image viewers and other activities that hide system bars) now open windowed on a Desktop display instead of a fullscreen plane. Games and unresizable activities still start fullscreen, and explicit or remembered modes keep precedence.
- Wayland windows support direct multitouch. A finger still clicks in applications that only understand a mouse.
