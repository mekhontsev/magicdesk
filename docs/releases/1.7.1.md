# MagicDesk 1.7.1

MagicDesk 1.7.1 is a stability update for external desktop sessions.

- Keeps freeform tasks away from the phone launcher while an external desktop
  is active and improves cleanup after display and session transitions.
- Improves pointer and keyboard recovery when the phone screen is turned off
  or input devices change state.
- Preserves system-selected external display modes and expands compatible
  Qualcomm display-mode discovery.
- Clarifies that privileged features use an authorized Android shell identity,
  currently connected through Shizuku.
