# MagicDesk 1.13

## Linux Applications

- Wayland joins X11: run individual Linux applications in separate Android
  windows, or a whole Linux desktop inside one window. Programs can come from
  Termux, proot or a prepared chroot. Termux-backed applications work without
  Shizuku, root or a MagicDesk Desktop session, including inside Samsung DeX.
- Both protocols share keyboard and IME integration, native application cursors,
  clipboard and copy drag-and-drop for text, HTML, images and files. Per-app
  interface scale is adjustable from 50% to 200%, saved for later launches and
  applied to running sessions.
- In MagicDesk Desktop, Linux menus, dialogs and popups can extend beyond their
  parent window. Supported Linux panels and backgrounds can also join a
  MagicDesk workspace instead of staying inside a separate Linux desktop window.
- X11 and Wayland use a shared Vulkan renderer with software fallback. Wayland
  supports compatible linear DMA-BUF client buffers; client GPU acceleration
  still depends on the Linux environment and device driver.

## Desktop And Automation

- Improved focus and task switching between fullscreen, floating and independent
  Android windows. Fixes cover native caption maximize/restore, keyboard action
  targets, launch and close handoffs, and resuming visible fullscreen applications.
- Live light/dark system-theme selection for Desktop sessions, clearer Limited
  Desktop status, and more consistent taskbar reveal on the phone.
- Unified MCP controls and inspection for X11/Wayland sessions, native window
  families and shell workspaces. `graphics.set_scale` uses the same scale
  preferences as Start and the Linux graphics manager.

Android 14+ for independent tools and Linux application hosts; Android 15+ for
managed Desktop. ARM64 only. Desktop requires Shizuku or root and device setup;
Termux integration requires its RUN_COMMAND permission.
