MagicDesk 1.5.0 adds wireless desktop sessions and improves behavior across
wired, wireless, and phone-hosted desktops.

- Runs full desktop sessions on Miracast wireless displays selected through the
  phone's casting interface.
- Provides a fallback MagicDesk phone touchpad for wireless sessions when the
  nubia touch panel is unavailable.
- Unifies keyboard and pointer routing across desktop display types, including
  physical-device hotplug, key repeat, and keyboard-layout switching.
- Improves recovery of the phone UI after a wired or wireless display is
  disconnected.
- Adds taskbar edge reveal over fullscreen applications and a simulated-display
  compatibility self-test with a shareable diagnostic report.

Requires Android 16 / API 36 or newer and an authorized Shizuku service.
