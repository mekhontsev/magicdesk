MagicDesk 1.4.5 expands the desktop workspace and external-display controls.

- Adds Android widgets with placement, resize, reconfiguration, and a clear
  provider picker that distinguishes widgets from the same application.
- Uses a consistent global desktop workspace for application shortcuts and
  files from the standard Android `Desktop` folder.
- Detects the connected display's available resolutions and refresh rates and
  offers them before starting the external desktop.
- Improves nubia touchpad integration, external pointer sensitivity, and
  cleanup of vendor desktop controls while MagicDesk is active.

Requires Android 16 / API 36 or newer and an authorized Shizuku service.
