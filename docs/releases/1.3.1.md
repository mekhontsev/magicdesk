MagicDesk 1.3.1 improves recovery and uninstall safety.

- Protects the phone launcher while a desktop is running on the phone display
  and restores normal Home/Recents navigation when that session closes.
- Adds an always-available **Restore defaults** action that removes MagicDesk
  desktop and primary-display overrides even after the app has been reinstalled.
- Explains how to restore nubia defaults before uninstalling MagicDesk.

Requires Android 16 / API 36 or newer and an authorized Shizuku service.
