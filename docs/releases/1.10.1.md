# MagicDesk 1.10.1

- Fixed Desktop startup with root Shizuku and missed Start/taskbar clicks on
  affected firmware. Root remains optional.
- Fixed phone-touchpad cursor creation on older kernels.
- Added optional protection against windows jumping during app navigation.
- Unsupported desktop eligibility and rounded-corner settings no longer block
  Desktop setup or request a reboot on their own.
- Added a reset to platform defaults for compatibility settings.
- Expanded MCP with Android UI inspection, actions, gestures and UI waits,
  usable without starting Desktop.
- Improved diagnostics and self-tests.

Android 14+ for tools and automation; Android 15+ for Desktop. ARM64 only.
See [compatibility and known limitations](https://github.com/mekhontsev/magicdesk/blob/v1.10.1/docs/compatibility.md).
