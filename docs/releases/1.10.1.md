# MagicDesk 1.10.1

This update improves desktop startup and phone-pointer compatibility, makes
optional firmware settings non-blocking, and expands independent Android UI
automation.

## Desktop And Input

- Desktop HOME startup uses the same explicit launch contract with Shizuku
  running as shell (UID 2000) or root (UID 0). Root is not required.
- Secondary HOME delegates no longer enter a repeated launch/finish loop.
  Desktop startup does not enable system navigation bars on secondary displays,
  avoiding intercepted Start and taskbar clicks on affected firmware.
- Activity handoff repair preserves a window's previous mode and geometry when
  firmware moves or resizes it during navigation. This optional compatibility
  setting is enabled by default on stock Nubia firmware.
- The phone touchpad negotiates the kernel's supported uinput setup protocol,
  including older kernels. Diagnostics identifies pointer-creation failures,
  and self-tests verify the real virtual pointer separately from injected input.
- Compatibility settings can be reset to platform defaults together with the
  optional Android external desktop-mode setting.

## Setup And Diagnostics

- The desktop eligibility and rounded-corner properties are optional. Failed
  writes or resets are reported without blocking Desktop or the other property.
  A failed optional write alone no longer requests a reboot.
- Setup and Diagnostics preserve actual property values. An unset property
  does not count as a disabled restriction or proof of unavailable freeform
  support; self-tests verify actual window behavior.
- Failed secondary HOME launches retain more framework evidence in reports.
- The immersive self-test fixture restores its state after Activity recreation.

## Android UI Automation

- MCP can inspect Android accessibility windows and nodes, perform supported
  node actions, and wait for exact UI conditions without starting Desktop.
- Added explicit-display touch gestures, key chords, atomic pointer clicks,
  and bounded screen-awake leases.
- Content-reading and input permissions remain separate. Password content is
  redacted, stale node handles are rejected, and UI actions require observation
  of their result rather than assuming an accepted request succeeded.

## Requirements And Known Limitations

- APK: Android 14 / API 34 or newer. Managed Desktop: Android 15 / API 35 or newer.
  Privileged operations require authorized Shizuku. Native helpers are ARM64;
  Android 14 device validation remains pending.
- HOME and pointer changes were exercised on RedMagic 11 Pro and OnePlus 5
  LineageOS under both shell and root Shizuku. Compatibility remains dependent
  on actual firmware behavior.
- Application-requested immersive fullscreen remains a known limitation on
  the tested LineageOS firmware. Abrupt display removal can leave system
  transition state on affected firmware. These limitations are not resolved
  by this release.
