MagicDesk 1.2.1 fixes external input behavior discovered after the 1.2
release.

## Fixes

- Physical mouse right click reaches Android applications and MagicDesk menus
  instead of being converted to system Back on the external display.
- Clicking the taskbar language indicator opens a desktop menu of enabled input
  methods without waking or redirecting interaction to the phone screen.
- Physical keyboard layouts are discovered consistently across enabled input
  methods, preserving fast `Ctrl+Space` language switching without input
  viewport flicker or cursor jumps.

## Requirements

- ZTE, nubia, or RedMagic device running Android 16 / API 36 or newer.
- Official Shizuku started through wireless debugging or ADB as shell UID 2000.
- One-time Device Setup followed by a reboot.

Only RedMagic 11 Pro firmware is currently verified. Other compatible ZTE or
nubia Android 16 builds can continue after an explicit warning and should use
MagicDesk Diagnostics when reporting firmware-specific issues.
