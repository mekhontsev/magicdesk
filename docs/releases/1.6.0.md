MagicDesk 1.6.0 substantially improves desktop-session stability.

- Greatly improves task and launcher recovery after normal exit or an
  unexpected wired or wireless display disconnect.
- Remembers application launch mode and window placement across displays.
- Adds file drag-and-drop between the desktop and compatible applications.
- Improves windowed launches, right click, and desktop item dragging.

Requires Android 16 / API 36 or newer and an authorized Shizuku service.
