# MagicDesk 1.9.1

MagicDesk 1.9.1 is a windowing and input reliability release.

## Changes

- Wired and wireless sessions now use the Android display that actually hosts
  their tasks, reducing transport-specific lifecycle and cleanup work.
- Freeform tasks follow the standard Android desktop path, while fullscreen
  tasks retain independent ordering planes where firmware requires them.
  Taskbar, Open tasks, `Alt+Tab`, Show Desktop, and MCP share the same workspace
  activation model.
- Windowed launches no longer expose an application's temporary framework
  startup mode before its final freeform placement.
- Physical keyboard and pointer routing has a simpler handoff sequence and
  recovers cleanly when devices are attached, replaced, or reused by a new
  desktop session.
- Self-test sessions are isolated from saved workspaces and MCP now starts the
  Diagnostics controller explicitly on the phone display.

## Requirements

- Android 15 / API 35 or newer
- The official Shizuku application with an authorized running service
- Firmware with usable native Android freeform windows

Use **Close desktop** before installing the update. Root is not required.
