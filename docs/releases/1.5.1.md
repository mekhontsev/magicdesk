MagicDesk 1.5.1 improves the phone touchpad for wired and wireless desktops.

- Makes pointer movement, drag, right click, scrolling, and text input more
  reliable across HDMI and Miracast sessions.
- Fixes cursor startup and keeps the touchpad available during application and
  window transitions.
- Adds a built-in reference for touch gestures and keyboard shortcuts.

Requires Android 16 / API 36 or newer and an authorized Shizuku service.
