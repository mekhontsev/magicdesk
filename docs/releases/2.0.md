# MagicDesk 2.0

## Linux Without Termux Or Root

**Shroot** is MagicDesk's new experimental Linux runtime. Run ARM64 glibc/musl
distributions and OCI images through Shizuku or Shevery's shell access, without
Termux, PRoot or Android root. Applications use MagicDesk's existing terminals,
X11 and Wayland windows; a whole Linux desktop can run inside a viewer.

- Install and retain several independent environments, with shared image layers,
  copy-on-write storage, explicit folder attachments and backup/restore.
- Find installed Linux applications in Start, open environment terminals and
  manage running launches through the same UI, CLI and MCP services.
- Use Linux package managers and development tools, including supported
  GDB/LLDB and strace workflows. Application seccomp filters remain supported.
- Optionally allow Linux commands to control MagicDesk and Android through the
  shared `magicdesk` CLI. This also works with native Termux and PRoot launches.

The interactive installer offers Debian, Ubuntu, Alpine, Fedora and Arch Linux
ARM profiles, console tools, individual GUI applications and desktop environments.
Installation runs visibly in a console. Optional Turnip setup builds a private
Mesa for compatible Adreno devices, including the Wayland/Zink patch.

In a MagicDesk Shell console:

```sh
magicdesk download https://raw.githubusercontent.com/mekhontsev/magicdesk/main/scripts/install_linux.sh ~/install_linux.sh
sh ~/install_linux.sh
```

Shroot requires supported kernel capabilities and is not a security sandbox or
Docker Engine. Use trusted images and programs. GUI and GPU compatibility varies
by distribution and device; see the [installer and runtime guide](https://github.com/mekhontsev/magicdesk/blob/v2.0/docs/guest-runtime.md).

## Native Themes

- Live appearance previews, JSON/ZIP theme import/export and per-workspace settings.
- Configurable panels and floating docks, adaptive Start layouts, icon magnification,
  semantic controls, light/dark palettes, transparency and optional system blur.
- Six bundled themes: Workbench, Material, Cupertino, Glass Dock, Two Panels and Contours.
- Animated images, silent video loops and AGSL shader wallpapers, with optional
  demand-driven CPU, RAM and battery signals.

## Everyday Use

- UI translations and per-app language selection: English, Russian, Simplified
  Chinese, Spanish, German, Japanese, Brazilian Portuguese and French.
- Independent display input on Android 14, separate keyboard placement and a
  touchpad button for showing the Android keyboard.
- Improved X11/Wayland startup surfaces, child-window ordering, resize constraints
  and Linux light/dark preference integration.
- More consistent taskbar/fullscreen handling and automatic adoption of freeform
  tasks on an active Desktop display.

Android 14+ for shared tools and Linux hosts; Android 15+ for managed Desktop.
ARM64 only. Desktop requires authorized shell/root access and device setup.
Termux-backed applications remain usable without Shizuku or root.
