# MagicDesk 2.2.0.1

- Faster Shroot with automatic lazy SVC acceleration and optimized filesystem
  operations.
- Improved Linux compatibility with systemd, containers, Flatpak, Snap and
  desktop applications.
- Expanded networking: IPv6, named network configurations and container port
  forwarding.
- Improved Turnip graphics, browser hardware composition and X11/Wayland input
  handling.
- Updated Linux installation recipes, including SteamOS and NixOS, with
  resumable setup and Android locale integration.
- Console command history, an existing-session picker and improved Android
  Recents integration.
- Console attachments from files, folders, camera and clipboard, accessible
  inside Linux sessions and cleaned up when the session ends.
- Linux automation through MCP and CLI, including AT-SPI2 UI actions and D-Bus.
- Multiple Shizuku providers configurable as an ordered package list.
