# MagicDesk 1.12.3

- Improved two-finger touchpad scrolling in X11 applications.
- X11 application cursors now use the Android pointer, without a second cursor.
- Fixed touchpad clicks in X11 menus and spurious errors when closing X11 windows.
- Phone Desktop: optional fullscreen launches by default; Home reveals the taskbar.
- Keep the phone screen on and disable adaptive brightness in any Desktop mode.
- Simpler virtual-display creation with a phone-preview checkbox.

[Download and setup](https://github.com/mekhontsev/magicdesk/blob/v1.12.3/docs/getting-started.md)
