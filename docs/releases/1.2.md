MagicDesk 1.2 stabilizes application launch, window transitions, and taskbar
minimization after the initial Shizuku-based 1.1 release.

## Highlights

- Starting an external desktop from a portrait phone no longer races Nubia's
  foreground-activity check or remains stuck in screen mirroring.
- Applications launch directly into Auto, Windowed, or Fullscreen mode without
  first flashing as a fullscreen phone application.
- User-selected window modes survive application restarts, while Auto mode
  continues to apply compatibility policy for games and other fullscreen-first
  applications.
- Cold fullscreen launches and later freeform/fullscreen transitions preserve
  correct geometry and remove stale REDMAGIC caption insets.
- Repeated clicks on an active taskbar icon and `Win+Down` minimize the window
  behind the desktop without stopping it. Media and other resumed work continue
  while the task is hidden.
- Android chooser and other transient system windows no longer permanently move
  or resize their owning application, hide the taskbar, or bury confirmation
  dialogs behind application windows.
- Application right click and the REDMAGIC phone touchpad are restored reliably
  after window and focus transitions.
- Fresh desktop sessions use a prepared native freeform launch anchor, and the
  desktop host no longer displays an unwanted caption strip.

## Requirements

- ZTE, nubia, or REDMAGIC device running Android 16 / API 36 or newer.
- Official Shizuku started through wireless debugging or ADB as shell UID 2000.
- One-time Device Setup followed by a reboot.

Only REDMAGIC 11 Pro firmware is currently verified. Other compatible ZTE or
nubia Android 16 builds can continue after an explicit warning and should use
MagicDesk Diagnostics when reporting firmware-specific issues.
