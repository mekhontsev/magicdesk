# MagicDesk 1.12.1

- X11 apps can request fullscreen, including video playback, without caption
  gaps. Fixed renderer locking and UI freezes.
- Start shares Android and Termux app discovery, shows cached Termux app icons,
  and keeps separate recent launches for Desktop and independent use.
- New-instance launches now create a separate task or report that the app does
  not support it, instead of silently reusing an existing window.
- Hold Win and use arrow keys for half/quarter window snapping. More Desktop
  actions are available through pointer menus, without keyboard shortcuts.
- Clearer Access, Termux and Desktop readiness; independent tools remain usable
  without Desktop setup. Improved phone Home/Overview and fullscreen placement.
- Improved display names and keyboard routing; X11 Android hosting is now owned
  by MagicDesk, with a focused native engine.

Android 14+ for tools and automation; Android 15+ for Desktop. ARM64 only.
Root is optional. X11 programs require Termux and its RUN_COMMAND permission.
[Download and setup](https://github.com/mekhontsev/magicdesk/blob/v1.12.1/docs/getting-started.md)
