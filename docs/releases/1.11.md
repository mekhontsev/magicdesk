# MagicDesk 1.11

- Independent desktops on multiple displays, with one Start launcher that can
  launch apps and move running tasks to a chosen screen.
- A richer terminal: Nerd Font, Sixel/Kitty images, clickable links, shell
  integration, touch scrolling, selection handles, and unified terminal/tmux
  sessions. Save or share terminal images through Android.
- Direct root support without Shizuku, plus an independent option to limit the
  service to shell UID 2000. Root remains optional.
- Built-in `magicdesk` CLI using the same commands as MCP. Display input,
  application placement and shared tools also work without Desktop.
- Improved Android UI automation, rectangular screenshots, HOME handling and
  session cleanup.

Android 14+ for tools and automation; Android 15+ for Desktop. ARM64 only.
