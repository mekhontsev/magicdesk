# MagicDesk 1.12

- Embedded X11: launch installed Termux apps such as GIMP and Firefox from
  Start, in separate Android windows, or run a full proot/chroot Linux desktop.
  No separate Termux:X11 APK needed. Clipboard and copy drag-and-drop support
  text, HTML, images and files between compatible Android and X11 apps.
- Portable desktops: keep applications running on a virtual display, show it
  on HDMI or a wireless output, disconnect, and reconnect without moving or
  relaunching the applications. A unified display panel manages desktops,
  viewers and input; keyboard switching changes both the view and input target.
- Task Manager now includes terminal, tmux and X11 processes, with CPU/memory
  usage, sorting and process controls.
- Smoother terminal scrolling, terminal access from notifications, unified
  recent launches, and expanded CLI/MCP automation.
- MagicDesk is now GPLv3-only. The matching source archive, including the
  embedded X11 fork and its dependencies, is included with the release.

Android 14+ for tools and automation; Android 15+ for Desktop. ARM64 only.
Root is optional. X11 programs require Termux and its RUN_COMMAND permission.
