# MagicDesk 1.9.2

MagicDesk 1.9.2 improves input diagnostics and session reliability.

## Changes

- Compatibility reports now capture the live keyboard and pointer relay state,
  including device generations, routing, event flow, cursor position when the
  platform exposes it, and recent reactivation attempts. This adds no
  continuous monitoring outside the existing input relay.
- Repeated Nubia launcher failures are contained during an active desktop
  session so one crash does not leave the phone UI unprotected.
- RedMagic cooling controls are probed through the active shell identity,
  avoiding package and UID mismatches when Shizuku runs as the shell user.
- A new optional setting disables adaptive brightness while a wired or
  wireless desktop is active and restores it when the session ends if
  MagicDesk changed the mode.
- Closing one of several fullscreen tasks now transfers focus to the surviving
  fullscreen task in the same window transaction.

## Requirements

- Android 15 / API 35 or newer
- The official Shizuku application with an authorized running service
- Firmware with usable native Android freeform windows

Use **Close desktop** before installing the update. Root is not required.
