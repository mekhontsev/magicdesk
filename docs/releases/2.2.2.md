# MagicDesk 2.2.2

- Improved Wayland frame pacing and reduced idle rendering overhead.
- Added a software-rendering option for X11 and Wayland.
- Improved Vulkan initialization and expanded graphics diagnostics.
- Expanded Shroot networking for VPNs, libvirt/QEMU and rootless containers,
  including policy routing and improved NAT.
- Reduced Shroot overhead in process supervision, `/proc` access and directory
  operations.
