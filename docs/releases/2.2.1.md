# MagicDesk 2.2.1

- Added rootless Docker and Podman support in Shroot.
- Added TUN/TAP networking for applications such as tun2socks and QEMU, with
  IPv4/IPv6 support.
- Improved Linux graphical application startup and session lifetime handling.
- Improved AT-SPI2 automation reliability when inspecting large interfaces or
  unresponsive applications.
- Fixed Running to include built-in tools and Linux windows, keeping separate
  windows individually selectable.
