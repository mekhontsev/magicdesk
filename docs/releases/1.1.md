MagicDesk 1.1 replaces the root-dependent 1.0 runtime with an official
Shizuku UserService running as Android shell UID 2000. The main APK no longer
requests root and deliberately refuses root/Sui Shizuku backends.

## Highlights

- Native overlapping Android desktop windows with WMShell captions, resize,
  snap, maximize, fullscreen, task focus, Show Desktop, and layout restore.
- Physical keyboard and mouse routing on the external display, including key
  repeat, multiple hot-plugged devices, `Ctrl+Space` layout switching,
  application right click, and DeX-style global shortcuts.
- App-requested fullscreen support for browser video and reliable transitions
  between freeform and true fullscreen tasks.
- Start menu, global Recents, taskbar context menus, desktop shortcuts and
  folders, notification center, calendar, screenshots, and phone touchpad.
- Shizuku-backed Device Setup, display DPI, screen control, wallpaper access,
  REDMAGIC bypass charging, cooling fan, liquid pump, and diagnostics.
- A guided first run that shows only the next required action and provisions
  MagicDesk's app-specific desktop permission through Shizuku.
- Refactored activity, task, input, display, and vendor integration boundaries
  with lifecycle-owned services that release input and display state on exit.

## Requirements

- ZTE, nubia, or REDMAGIC device running Android 16 / API 36 or newer.
- Official Shizuku started through wireless debugging or ADB as shell UID 2000.
- One-time Device Setup followed by a reboot.

Only REDMAGIC 11 Pro firmware is currently verified. Other compatible ZTE or
nubia Android 16 builds can continue after an explicit warning and should use
MagicDesk Diagnostics when reporting firmware-specific issues.
