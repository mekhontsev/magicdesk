# MagicDesk 1.8.0

MagicDesk 1.8.0 expands the native Android workspace and substantially rebuilds
its desktop runtime for more predictable task, display, and input lifecycles.

- Adds richer built-in Files and Console workflows, Task Manager with resource
  monitoring and app logs, unified Start search, and taskbar overflow.
- Improves seamless window, fullscreen, cross-display, Alt+Tab, task parking,
  and session restoration transitions while strengthening phone-launcher
  isolation and cleanup.
- Improves pointer routing startup and teardown, keyboard focus, physical input
  handling, and phone taskbar access.
- Extends display-mode discovery, recording audio choices, Standard Android and
  SoC integration, and simulated-display compatibility testing.
- Targets Android 17 while retaining Android 15 as the minimum supported
  platform.
