# MagicDesk 2.3

- Run Shroot Linux as **User**, without Shizuku or Android root. Verified on Alpine with runc, single-node k3s and sandboxed Chromium.
- Choose **User** or **Shell** consoles, each with its own Linux library. The Linux installer uses the selected console's environment.
- Run X11 and Wayland sessions without an Android window or virtual display. Manage retained graphical sessions and attach a viewer when needed.
- Keep the phone awake behind a black, dimmed screen; press a volume key to return. Available from Control Panel and MCP.
- Use hardware screen-off controls independently of managed Desktop, where supported.
- Improve Desktop startup compatibility with newer Android frameworks and report underlying system errors, HOME role-service diagnostics and the selected shell manager's version.
