# MagicDesk 2.3

- **Linux Capsules:** turn a distribution into a standalone Android APK with its own UID, private data and terminal. It runs without MagicDesk, Shizuku or root. Choose whether it gets network access and which Android folders it can read or write.
- **Rootless Linux with Shroot 1.0:** install a distribution from a User console or keep a separate Shell library. On Alpine, User mode runs sandboxed Chromium, runc containers and single-node k3s.
- **Linux graphics:** start X11 and Wayland sessions without a display and attach a viewer when you need one.
- **Console sharing:** send files or text from Android to an open console, or compose text in the paperclip editor.
- **Phone controls:** check Android's background process limit in Control Panel. Keep the phone awake with a black, dimmed screen; press a volume key to return.
- **Desktop compatibility:** improved startup on newer Android firmware, including devices that keep their system launcher as Home.
