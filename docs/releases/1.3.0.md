MagicDesk 1.3 focuses on desktop stability and compatibility.

- Protects RedMagic Home and launcher state when desktop sessions end or an
  external display is disconnected.
- Restores keyboard and mouse handling after Shizuku restarts, device
  reconnects, and display transitions.
- Preserves running applications during freeform/fullscreen transitions and
  removes stale RedMagic caption bars.

Requires Android 16 / API 36 or newer and an authorized Shizuku service.
RedMagic 11 Pro is the currently verified device; other compatible ZTE, nubia,
and RedMagic Android 16 firmware remains experimental.
