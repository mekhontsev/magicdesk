MagicDesk 1.3 improves desktop-session recovery, input reliability, and
compatibility across ZTE, nubia, and REDMAGIC firmware variants.

## Highlights

- Phone Home and launcher state are protected when a local desktop closes,
  MagicDesk is interrupted, or an external display is removed.
- Stale freeform and Recent tasks are reconciled before returning control to
  the phone launcher, including state left by an earlier process or reboot.
- External desktop overlays follow live permission changes and restore the
  taskbar without restarting MagicDesk.
- Keyboard and mouse handling recovers cleanly after Shizuku service restarts,
  input-device reconnects, and display transitions.
- Official Shizuku is supported whether its service was started through ADB,
  wireless debugging, or root; MagicDesk still uses only Shizuku APIs.
- External desktop startup is disabled until a physical external display is
  available, avoiding invalid or stale Nubia display sessions.
- Selected launcher-hidden REDMAGIC utilities are available from the MagicDesk
  application catalog when present on the device.
- Monitor identification retries are bounded per physical connection, and app
  icons no longer depend on Nubia's optional launcher icon cache.
- Freeform-to-fullscreen transitions clear stale REDMAGIC caption insets
  without changing display density or recreating the application Activity.

## Requirements

- ZTE, nubia, or REDMAGIC device running Android 16 / API 36 or newer.
- Official Shizuku with MagicDesk access authorized.
- One-time Device Setup followed by a reboot.

Only REDMAGIC 11 Pro firmware is currently verified. Other compatible ZTE or
nubia Android 16 builds can continue after an explicit warning and should use
MagicDesk Diagnostics when reporting firmware-specific issues.
