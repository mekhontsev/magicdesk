# MagicDesk 1.12.2

- Linux launchers for Termux, PRoot and chroot. Root users can run terminals and
  X11 applications in a prepared chroot without Termux.
- Improved X11 startup, dialogs, menus and per-app window placement. Closing a
  window respects application confirmation dialogs; cross-window and guest
  filesystem drag-and-drop are more reliable.
- Task-targeted screenshots and Android UI automation, plus read-only X11
  window-family inspection through MCP.
- Startup limits for access level, Termux and Desktop; clearer Termux setup
  and more display operations without privileged access.
- Always-unlocked virtual displays where supported, and phone-screen power
  control for simulated desktops.
- Preserve manually arranged windows across application restarts. Updated
  framework adapters and local-network permission handling for Android 17.
- Nubia protection against password-field flicker on external displays, and
  improved window ordering when closing Desktop.

Android 14+ for tools and automation; Android 15+ for Desktop. ARM64 only.
Root is optional except for shell-hosted chroot.
